# Hello MCP

A simple Model Context Protocol (MCP) server that provides two tools:

- `get_greeting(name)`: returns a greeting for the supplied name.
- `add_numbers(a, b)`: returns the sum of two integers.

The server is configured for VS Code in `.vscode/mcp.json` and runs with the
project's Python environment.
